This file outlines the general rules to use for the appearance of components and UI, the conventions and hard rules.

# Colors
In all aspects a darkerand lighter shade is needed for effects such as hover, press and the like
```
{
  background-color: #222B25 - Dark background to be used by major layout components
  text-color: #FFF2D6
  primary-color: #3884FF
  secondary-color: #1C9A11
  tertiary-color: #263E62
  accent-color: #B47AF2
  info-color: #6ba3ff
  warn-color: #e5a820
  error-color: #e5484d
} 
```
# Font
SN Pro - https://fonts.google.com/specimen/SN+Pro for all
# Icons
MingCute icon pack from Iconify - https://icon-sets.iconify.design/mingcute/

Also, as the icon pack supports fill and line variants of most icons (e.g: `information-line` and `information-fill`) use line icons for most actions and for interactivity switch them for fill variants.
## Icon generics
{
  info : mingcute:information-line
  warning : mingcute:alert-line
  error : mingcute:alert-octagon-line
}
